# KSR International Trade Manufacturing

Website of KSR International Trade Manufacturing, an Indian spice manufacturer and exporter based in Ambad, Jalna, Maharashtra.

Single-file static website (HTML, compiled Tailwind CSS and JavaScript). No build step required.

## Pages
Home, Products, Certificates & Compliance, About Us, Why Choose Us, Contact and Quotation.

## Deploy with GitHub Pages
1. Settings > Pages
2. Source: Deploy from a branch, Branch: main, Folder: / (root)
3. Save. The site goes live at https://USERNAME.github.io/REPOSITORY/

## Updating content
Edit with the private control panel (`admin.html`, kept on the owner's computer, not in this repo), download the updated file, rename it to `index.html` and replace it in this repository.
